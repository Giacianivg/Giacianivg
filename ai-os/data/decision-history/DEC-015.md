## Decisão Técnica Pendente (CTO)

**Antes de implementar PLU-12 (Vouchers PDF):**

@architect deve avaliar e decidir entre:

| Opção | Prós | Contras |
|-------|------|---------|
| `jsPDF` (client-side) | Zero impacto server, sem cold start | Layout limitado, sem imagens complexas |
| `html-pdf-node` | HTML→PDF completo, fácil de usar | +50MB bundle, pode exceder Vercel limit |
| `Puppeteer` (serverless) | Alta fidelidade | Cold start >5s, incompatível com limit 200ms do webhook |
| `@react-pdf/renderer` | Componentes React, PDF perfeito | Requer React no projeto (não usa atualmente) |
| **Recomendação preliminar** | `jsPDF` com template HTML manual ou `html-pdf-node` em rota separada | — |
