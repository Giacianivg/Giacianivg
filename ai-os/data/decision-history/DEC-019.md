## Especificação Técnica

### S-01 — Ativar WHATSAPP_APP_SECRET (@devops)

**Onde:** Vercel Dashboard → Settings → Environment Variables

```
WHATSAPP_APP_SECRET = <app_secret do Meta Business Portal>
```

**Como obter:**
1. Meta Business Portal → Apps → Seu App
2. "Configurações do app" → "Segurança" → App Secret → Mostrar

**Efeito imediato após redeploy:**
```javascript
// webhook.js:32-35 — código já existente, ativa automaticamente:
if (!appSecret) {
  console.warn('[security] WHATSAPP_APP_SECRET not configured — skipping signature validation');
  return next(); // ← isso para de acontecer
}
```

**Verificação:**
```bash
# Simular POST sem assinatura — deve retornar 403:
curl -X POST https://webhook-six-topaz.vercel.app/webhook \
  -H "Content-Type: application/json" \
  -d '{"test": true}'
# Esperado: {"error":"missing_signature"}
```

### S-03 — Logging Estruturado (@dev)

**Objetivo:** Cada request tem `requestId` único. Logs são JSON parseável. Erros têm contexto.

**Padrão de log:**
```javascript
// Estrutura alvo:
{
  "ts": "2026-03-14T10:30:00.000Z",
  "level": "info|warn|error",
  "requestId": "wh_1710415800123_abc123",
  "service": "webhook|crm",
  "event": "message_received|quotation_sent|error",
  "phone": "5519XXXXXXXX",   // apenas para webhook
  "route": "POST /webhook",  // apenas para CRM
  "durationMs": 342,
  "data": {}                  // contexto adicional
}
```

**Arquivos a modificar:**
- `services/whatsapp/webhook.js` — adicionar requestId por mensagem + log estruturado nos eventos principais
- `server.js` — adicionar request logger middleware (requestId por request HTTP)

**Sem dependências externas** — usar `JSON.stringify` nativo. Não instalar winston/pino.

**Eventos mínimos a logar:**

| Evento | Level | Dados |
|--------|-------|-------|
| Mensagem recebida | info | phone, messageId, type |
| Cotação enviada | info | phone, roomType, nights, total |
| Escalonamento | warn | phone, motivo |
| Confirmação de reserva | info | phone, reservationNumber |
| Erro Claude API | error | phone, errorCode, durationMs |
| Erro Supabase | error | operation, errorCode |
| Assinatura inválida | warn | ip, signature_prefix |
