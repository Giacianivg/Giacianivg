# DEC-007 — BLACKBOARD_MEMORY: Estado Compartilhado Real entre Agentes

**Data:** 2026-03-10
**Proposto por:** Vitor (Founder) via AIOS Master
**Status:** APROVADO — Vitor 2026-03-10

## Problema

Agentes operam no vacuo — sem contexto real do negocio.
Event Bus emite eventos mas ninguem persiste o estado.
Command Center mostra atividade mas nao mostra dados reais.
Decisoes do board sao baseadas em zero contexto operacional.

## Solucao: Blackboard como Abstracao Supabase

O Blackboard NAO e singleton in-memory.
Em Vercel (serverless), cada invocacao e uma nova instancia — singleton nao persiste.

**Decisao arquitetural CTO:** Blackboard e uma abstracao sobre Supabase com cache local de 60s.

```
system/blackboard.js
  ↓
Supabase (blackboard_state) ← fonte de verdade
  ↑
Cache local 60s ← evita round-trip por request
```

CREATE TABLE IF NOT EXISTS blackboard_state (
  key TEXT PRIMARY KEY,

-- Dados iniciais

### 2. `system/blackboard.js` — Singleton com Backend Supabase

Interface publica:

```js
// Leitura (usa cache 60s)
await blackboard.get('leads')       // → { total, ativos, score_medio, ultimo_update }
await blackboard.get('reservas')    // → { hoje, semana, mes, ocupacao_pct }
await blackboard.get('financeiro')  // → { mrr, cac, ticket_medio }
await blackboard.getState()         // → objeto completo { leads, reservas, financeiro, alertas }

// Escrita (async, nao bloqueia)
blackboard.set('leads', { total: 12, ativos: 8, ... })     // fire-and-forget
blackboard.pushAlerta({ type: 'IDLE', leadId: 'x', ... })  // adiciona na fila
```

Estrutura interna:

```js
const CACHE_TTL_MS = 60_000;
const cache = { data: {}, ts: 0 };

async function get(key) {
  if (Date.now() - cache.ts < CACHE_TTL_MS) return cache.data[key];
  const rows = await supabaseAdmin.from('blackboard_state').select('*');
  cache.data = Object.fromEntries(rows.data.map(r => [r.key, r.value]));
  cache.ts = Date.now();
  return cache.data[key];
}

function set(key, value) {
  cache.data[key] = value; // update cache imediato
  supabaseAdmin
    .from('blackboard_state')
    .upsert({ key, value, updated_at: new Date() })
    .then(() => {})
    .catch(err => console.error('[blackboard] write error:', err));
  // fire-and-forget — nunca bloqueia
}
```

### 3. Integracao Event Bus — `system/eventBus.js`

Adicionar listeners no Event Bus (apos inicializacao):

```js
eventBus.on('lead_received', async (data) => {
  const leads = await blackboard.get('leads');
  blackboard.set('leads', {
    ...leads,
    total: (leads.total || 0) + 1,
    ativos: (leads.ativos || 0) + 1,
    ultimo_update: new Date().toISOString()
  });
});

eventBus.on('booking_confirmed', async (data) => {
  const reservas = await blackboard.get('reservas');
  blackboard.set('reservas', {
    ...reservas,
    hoje: (reservas.hoje || 0) + 1,
    mes: (reservas.mes || 0) + 1
  });
});

eventBus.on('message_received', async () => {
  const leads = await blackboard.get('leads');
  blackboard.set('leads', { ...leads, ultimo_update: new Date().toISOString() });
});
```

### 4. API — `routes/blackboard.js`

```js
// GET /api/blackboard/state
router.get('/state', async (req, res) => {
  try {
    const state = await blackboard.getState();
    res.json({ ok: true, state, ts: Date.now() });
  } catch (err) {
    res.status(500).json({ ok: false, error: err.message });
  }
});
```

Montar em `server.js`:
```js
app.use('/api/blackboard', require('./routes/blackboard'));
```
