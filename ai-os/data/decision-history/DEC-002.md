# DEC-002 — EVENT_BUS + COMMAND_CENTER: Camada de Orquestração e Visibilidade do Sistema

**Data:** 2026-03-10
**Proposto por:** CTO Agent (retroativo — implementado antes da formalização)
**Status:** IMPLEMENTADO

## Contexto

Sistema operacional com Bot Luna funcionando e CRM ativo, porém sem visibilidade em tempo real das decisões dos agentes, eventos internos ou status do pipeline de orquestração. Gap identificado: o AIOS-Master não tinha interface para monitorar o fluxo de decisões entre agentes.

Decisão implementada usando **strangler pattern** — nova camada adicionada sem tocar no código existente. Zero breaking changes. 139/139 testes mantidos.

### Arquivos criados (commit db03451)

| Arquivo | Responsabilidade |
|---------|-----------------|
| `services/events/eventBus.js` | Event Bus central — pub/sub entre agentes |

| `services/ai/crmAgent.js` | Agent Layer — integra CRM com Decision Engine |
| `services/ai/queue.js` | Queue de processamento assíncrono de eventos |
| `routes/ai-activity.js` | API REST para leitura de atividade dos agentes |
| `public/command-center.html` | Command Center — dashboard de visibilidade do sistema |

## Arquitetura da Decisao

### Strangler Pattern aplicado

```
ANTES:
  server.js → routes/* → Supabase

DEPOIS:
  server.js → routes/* → Supabase
                       ↘
                        eventBus.js → decisionEngine.js → crmAgent.js
                                    ↘
                                     queue.js → ai-activity.js → command-center.html
```

Nenhuma rota existente foi modificada. O Event Bus escuta eventos emitidos opcionalmente pelo sistema existente.
