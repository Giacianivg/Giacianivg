## 3 Variacoes Obrigatorias por Campanha

`
VARIACAO A — Emocional
Sentimento que o hospede vai ter
Foto real do ambiente + frase sensorial
Exemplo: foto do cafe colonial com "Seu domingo comeca assim"

VARIACAO B — Racional
Proposta de valor clara
Foto + pacote + preco + disponibilidade
Exemplo: "2 noites + cafe para 2 — R900 — So 3 quartos"

VARIACAO C — Urgencia
Escassez real
Foto + disponibilidade limitada
Exemplo: "Pascoa quase lotada — 2 quartos restantes"
`
