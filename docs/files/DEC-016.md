# DEC-016 — AI-OS v2: Task Queue + Observabilidade + Memória Semântica

**Data da proposta:** 2026-03-12
**Data da decisão:** 2026-03-12
**Data de execução:** após Páscoa (2026-04-07+)
**Solicitante:** Founder (Vitor)
**Tipo:** Tecnologia / Infraestrutura AI-OS

---

## Proposta

Completar infraestrutura do AI-OS Hospitality com 3 peças faltantes identificadas por Orion:
Task Queue (Redis/Upstash) para paralelismo real, Observabilidade no dashboard para visibilidade
de operações dos agentes, e Memória Semântica (pgvector) para Luna aprender com cada conversa.

## Problema ou Oportunidade

O AI-OS atual opera com agentes efêmeros — sem persistência de tasks entre sessões, sem
visibilidade de o que cada agente faz/gasta, e Luna não aprende com histórico semântico.
Essas 3 peças completam a fundação operacional sem custo adicional (Upstash free + Supabase).
