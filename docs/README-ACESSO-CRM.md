## 🎯 Tarefas Rápidas

### "Quero ver as reservas de hoje"
1. Abra o CRM
2. Clique em "🗓️ Reservas"
3. Veja a data de hoje (marcada)
4. Pronto! ✅

📖 Detalhes completos em: `GUIA-ACESSO-CRIANCA.md` → seção "Reservas"

### "Quero responder um cliente"
1. Abra o CRM
2. Clique em "💬 Mensagens"
3. Encontre o cliente
4. Escreva sua resposta na caixa
5. Aperte "Enviar"
6. Pronto! ✅

📖 Detalhes completos em: `GUIA-ACESSO-CRIANCA.md` → seção "Conversa Completa"

### "Quero ver histórico de um cliente"
1. Abra o CRM
2. Clique em "📋 Histórico"
3. Escreva o nome do cliente
4. Clique no nome para ver tudo
5. Pronto! ✅

📖 Detalhes completos em: `GUIA-ACESSO-CRIANCA.md` → seção "Histórico"

| Pergunta | Resposta Rápida |
|----------|-----------------|
| Esqueci a senha | Não tem senha! Usa o link só |

- Dia 1: Dashboard
- Dia 2: Reservas

- Dia 5: Relatórios

- Depois fica fácil

- Anota as coisas mais frequentes
- Cria atalhos que fazem sentido pra você

## 🎁 Bônus: Atalhos de Teclado

Depois que aprender o básico, use esses atalhos:

| Atalho | O que faz |
|--------|-----------|
| `F5` | Atualiza a página (se travou) |
| `Ctrl+F` | Pesquisa no histórico |
| `Tab` | Navega entre campos |
| `Enter` | Envia mensagem |
| `Escape` | Fecha popup |
