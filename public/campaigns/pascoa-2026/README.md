| `feed-1200x628.html` | 1200×628px | Facebook Feed horizontal |

## Como exportar para PNG

### Opção A — Chrome (recomendado)

1. Abra o arquivo `.html` no Chrome
2. Pressione `F12` → aba **Device Toolbar** (ícone de celular)
3. Defina dimensões exatas:
   - Feed: `1080 × 1080`
   - Stories: `1080 × 1920`
   - Facebook: `1200 × 628`
4. Pressione `Ctrl+Shift+P` → digite `screenshot`
5. Selecione **"Capture full size screenshot"**
6. Salvo automaticamente como PNG na pasta Downloads

### Opção B — Extensão Chrome "GoFullPage"
1. Instale GoFullPage
2. Abra o HTML no Chrome
3. Clique no ícone da extensão → exporta PNG
